# Elegance - Perfumes Originales

Sitio web de catálogo de perfumes (HTML/CSS/JS), 100% estático.

- Catálogo de fragancias con filtros, búsqueda y ordenamiento
- Carrito de compras
- Pedidos coordinados por WhatsApp

## Ver el sitio
- URL GitHub Pages: https://matiasbrambilla477-jpg.github.io/perfumes/
- Repo: https://github.com/matiasbrambilla477-jpg/perfumes

(Si GitHub Pages no está activo, activá Pages desde Settings > Pages > Deploy from a branch > main / root.)

## Contenido
- index.html - página principal
- css/style.css - estilos
- js/products.js - datos de productos
- js/main.js - lógica del sitio
